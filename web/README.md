# RAG Pipeline Web Interface

This directory contains the FastAPI backend and React frontend for the RAG Pipeline web application.

## Development

### Backend (FastAPI)
```bash
# From project root
python -m web.app
# Or with uvicorn
uvicorn web.app:app --reload --port 8001
```

### Frontend (React + Vite)
```bash
cd web/frontend
npm install
npm run dev  # Development server on http://localhost:5173
```

## Production Build

### Build Frontend
```bash
cd web/frontend
npm install
npm run build
```

This generates static files in `web/static/` that are served by FastAPI.

**Note:** Build artifacts (`web/static/assets/*` and `web/static/index.html`) are git-ignored. You must run `npm run build` after cloning or pulling changes to generate the frontend bundle.

### Run Production Server
```bash
# From project root
uvicorn web.app:app --host 0.0.0.0 --port 8001
```

The FastAPI backend will serve the built React frontend at the root URL.

## Architecture

- **Backend**: FastAPI (`web/app.py`, `web/api/`)
- **Frontend**: React + TypeScript + Vite (`web/frontend/`)
- **Build Output**: `web/static/` (git-ignored, generated by `npm run build`)

## Admin Settings

The admin settings page (`/projects/:projectId/settings`) allows per-project configuration of:
- Embedding model and Hugging Face endpoint/token
- LLM model and endpoint/token
- Chunking parameters (target tokens, overlap)

Each project can use different AI models and endpoints independently.
